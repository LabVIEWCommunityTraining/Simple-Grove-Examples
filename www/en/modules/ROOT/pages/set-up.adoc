== Download and install the CTI Pico firmware (UF2)

. Download the latest CTI Pico firmware (UF2)

* https://github.com/LabVIEWCommunityTraining/cti-firmware/tags[UF2 Releases]

. Load firmware on the Pico by pressing the bootsel button and powering on the Pico.

[TIP]
=====
On a Radxa you could run this script instead (mainly because the Bootsel button is a bit fiddly!)...

.Reset Bash Script
[source,shell]
====
#! /bin/bash

gpioset gpiochip0 17=1

gpioset gpiochip0 7=1

sleep 1

gpioset gpiochip0 17=0

gpioset gpiochip0 7=0
====
